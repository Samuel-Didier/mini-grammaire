Introduction

Bienvenue dans la documentation technique du projet Ma Mini-Grammaire. Cette application web éducative aide les utilisateurs à améliorer leur français grâce à des outils interactifs.

Le projet est construit avec le micro-framework Fat-Free (F3) et suit une architecture MVC stricte.

Architecture

La structure du projet sépare clairement la logique métier, l'accès aux données et l'affichage.

/
├── App/
│   ├── Controllers/   # Logique de l'application
│   └── Models/        # Accès à la base de données
├── ui/
│   ├── pages/         # Contenu des pages
│   ├── partials/      # Éléments réutilisables (header, footer)
│   └── layout.html    # Gabarit principal
├── assets/            # CSS, JS, Images
└── index.php          # Point d'entrée (Front Controller)

Contrôleurs

Les contrôleurs gèrent les requêtes HTTP et préparent les données pour les vues.

Auth.php

Gère l'inscription, la connexion, la déconnexion et l'affichage du `profil` (avec calcul des stats).

  • login($f3) : Traite le formulaire de connexion.
  • register($f3) : Crée un nouvel utilisateur.
  • profil($f3) : Affiche le tableau de bord utilisateur avec ses stats.

Page.php

Gère l'affichage des pages statiques et la navigation principale.

  • home($f3) : Affiche le tableau de bord.
  • grammaire($f3) : Affiche le tableau des codes.
  • testNiveau($f3) : Affiche le test initial (avec vérification).

QuizController.php

Gère la logique des quiz et la sauvegarde de la progression.

  • saveLevel($f3) : API pour sauvegarder le résultat du test (AJAX).
  • index($f3) : Affiche le menu des quiz.

Modèles

Tous les modèles étendent \DB\SQL\Mapper pour faciliter le CRUD.

Modèle Table Description
User users Gestion des comptes utilisateurs.
Favori favoris Liaison entre utilisateurs et astuces favorites.
Progression progression Stockage des résultats de tests et niveaux.
Astuces astuces Contenu des astuces de grammaire.

Routes

Toutes les routes sont définies dans index.php et préfixées par /mini-grammaire.

GET  /                      -> Page->home
GET  /login                 -> Auth->login
POST /login                 -> Auth->login
GET  /register              -> Auth->register
POST /register              -> Auth->register
GET  /profile               -> Auth->profil
GET  /mini_grammaire        -> Page->grammaire
GET  /astuces               -> AstucesController->getAstuces
POST /favori/toggle/@id     -> FavorisController->toggle
GET  /test-niveau           -> Page->testNiveau
POST /quiz/save-level       -> QuizController->saveLevel

Vues & Templates

Le moteur de template de F3 est utilisé pour le rendu dynamique.

  • Layout : ui/layout.html contient la structure HTML de base.
  • Inclusion : <include href="partials/header.html" />
  • Variables : {{ @variable }}
  • Conditions : <check if="...">
  • Boucles : <repeat group="..." value="...">

Assets (CSS & JS)

Les ressources statiques sont organisées par fonctionnalité.

CSS

  • style.css : Styles globaux et layout.
  • auth.css : Styles des pages de connexion/inscription.
  • profile.css : Styles de la page profil.
  • quiz.css : Styles spécifiques aux quiz.
  • mini_grammaire.css : Styles du tableau de codes.

JavaScript

  • quiz.js : Logique complète du quiz (questions, progression, résultats, AJAX).
  • script_search.js : Moteur de recherche pour la mini-grammaire.
